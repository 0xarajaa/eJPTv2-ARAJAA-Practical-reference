# eJPTv2 ARAJAA Practical Reference

Welcome to my practical **eJPTv2 reference repository**.

This repository contains structured, hands-on notes created during my eJPTv2 learning journey. It is designed as a quick and practical reference for reviewing penetration-testing methodologies, tools, commands, and workflows.

> [!IMPORTANT]
> This is an unofficial, community-created study resource. It is not affiliated with, endorsed by, or sponsored by INE Security. The content is intended strictly for education and authorized security testing.

## What You Will Find

- Practical commands with clear explanations
- Information gathering and enumeration workflows
- Footprinting, scanning, and vulnerability assessment
- Host and network security auditing
- Linux and Windows exploitation techniques
- Privilege escalation and credential access concepts
- Web application penetration testing
- AI-enhanced penetration-testing concepts
